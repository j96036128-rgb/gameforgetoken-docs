# Contributors

This directory contains profiles of people who have contributed accepted work to GameForge.

## Purpose

Contributor profiles exist to acknowledge real work. They are not rewards, rankings, or status markers.

## What Profiles Are

- Factual records of accepted contributions
- Linked to specific Build Requests in the participation ledger
- Written in plain language without promotion

## What Profiles Are Not

- Rankings or leaderboards
- Scores or point systems
- Gamification of any kind

## Inclusion Criteria

A contributor profile is created when someone has at least one accepted entry in the participation ledger. No exceptions.

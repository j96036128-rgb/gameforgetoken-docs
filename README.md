# GameForgeToken Documentation

GameForgeToken is an early-stage protocol exploring a play-to-build model for decentralized game development.

This repository contains public documentation intended to provide transparency into the project's design philosophy, planned architecture, and development roadmap.

## 🚧 Project Status

- GameForgeToken is in **pre-mainnet development**
- The GFT token is **not live**
- No public or private token sale has occurred
- No smart contracts have been deployed to mainnet
- Features described in the whitepaper are **planned** and subject to testing, review, and iteration

This repository is provided for documentation and transparency purposes only.

---

## 🔍 What This Repository Is (and Is Not)

**This repository is:**
- A source of technical and conceptual documentation
- A reference for reviewers, grant programs, and early collaborators

**This repository is not:**
- A token sale page
- An investment solicitation
- A live product or protocol

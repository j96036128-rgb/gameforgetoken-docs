# GameForge Participation Ledger

This repository records participation in GameForge Build Requests during the pre-token phase.

## Purpose
- Provide transparent attribution for ecosystem contributions
- Document participation before any on-chain system exists
- Support prioritisation for future Build Requests

## Important Notes
- No token is live
- No financial rewards are provided
- Participation does not guarantee future token allocation
- This ledger may be discontinued if the experiment does not continue

All entries are recorded manually by the GameForge Core Review Group.

# GameForge Participation Ledger

This directory records participation in GameForge Build Requests during the pre-token phase.

## Purpose

- Provide transparent attribution for ecosystem contributions
- Document participation before any on-chain system exists
- Support prioritisation for future Build Requests

## Contents

| File | Description |
|------|-------------|
| `ledger.csv` | Master record of all accepted contributions |
| `build-request-XXX.md` | Individual Build Request specifications |
| `contributions/` | Detailed contribution records |
| `post-mortems/` | Build Request post-mortems and learnings |
| `WORKSPACE-MODEL.md` | How developers and contributors work together |
| `POST-MORTEM-TEMPLATE.md` | Template for documenting completed Build Requests |

## How Entries Are Added

1. Contributor completes work for an open Build Request
2. Core Review Group (CRG) reviews the submission
3. If accepted, CRG adds an entry to `ledger.csv`
4. Entry includes: Build Request ID, contributor, role, summary, date, status

## How to Participate

1. Review open Build Requests in this directory
2. Follow submission instructions in the specific Build Request file
3. Submit your contribution via GitHub Issue or PR
4. Wait for CRG review

- No financial rewards are provided

# Build Request #001 — Structured Prototype Playtesting

**Status:** Open
**Phase:** Manual Pilot
**Date Opened:** January 2026

## Objective
Test whether structured, contribution-based coordination can deliver useful feedback to early-stage game developers without financial incentives.

## Who This Is For
- Solo developers or small teams
- Early prototype or vertical slice
- Building on Solana or Solana-adjacent tooling

## What the Builder Receives
- Structured playtesting feedback
- Usability and clarity notes
- High-level technical observations (non-binding)

## What Contributors Do
- Play the prototype
- Submit feedback using a defined template
- Optionally participate in a short follow-up discussion

## Participation Credit
- Contributions are recorded in the public participation ledger
- Used to prioritise future Build Requests and contributor access
- No token distribution and no financial reward

## Scope Limits
- No funding provided
- No guarantees of outcomes
- No transfer of IP or code ownership
- Feedback only

## Success Criteria
- At least one completed Build Request
- Actionable feedback delivered to the builder
- Contributions documented publicly

## Context

Coordination Demo 001 is a minimal click-to-collect game built to demonstrate that the GameForge coordination loop works end-to-end. The demo is playable and was used to validate basic protocol functionality.

**Demo Repository:** https://github.com/j96036128-rgb/coordination-demo-001

**How to Play:** Open `game/index.html` in a browser. Click falling objects to collect them before time runs out.

---

## Request

Structured playtest feedback on the core mechanic.

### Scope

- Input reliability: Do clicks register consistently?
- Difficulty curve: Is the spawn rate and fall speed appropriate?
- Visual clarity: Can you clearly see objects and understand what to do?
- Session length: Is 30 seconds too short, too long, or appropriate?

### Out of Scope

- Feature suggestions
- Art/audio feedback
- Code review
